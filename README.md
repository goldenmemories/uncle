# Student Housing Management

A mobile-friendly application for managing student housing tenants, maintenance requests, and communications.

## Features
- Tenant management (add, edit, archive)
- Maintenance request tracking
- Email notifications to tenants
- Mobile-responsive design
- Dashboard with key metrics

## Technologies
- React
- Supabase (Database)
- Netlify (Hosting & Serverless Functions)
- Tailwind CSS (Styling)

## Setup
1. Clone this repository
2. Install dependencies: `npm install`
3. Create a `.env.local` file with your Supabase credentials
4. Run locally: `npm start` or `netlify dev`

## Deployment
The application is automatically deployed via Netlify when changes are pushed to the main branch.
